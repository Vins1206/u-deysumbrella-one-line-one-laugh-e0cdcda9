## What it does

`main.py` (pure Python standard library, no input, no network) writes one
funny line — a single joke, 61 characters, well inside the 140-character
gate — to `/output/entry.txt`:

> I told my umbrella it was my only cover story, and it leaked.

The program self-checks the gate before writing: the line must be 1–140
characters, not only whitespace, and contain no newline.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
